## Why the foundation changes

The serialized name **character_portfolio** is correct. Preserve it and **council**; Individual/Monarchy are presentation labels. The old plural spelling was prose drift, not a software defect or the reason for Step 01.

Average-cost relief is a legitimate convention. The approved plan chooses **FIFO** for traceable lot relief, so Step 02 adds it explicitly and preserves historical average-cost results. For identical fills, fees and marks, FIFO changes the realized/unrealized split, not total equity or total pre-tax economic P/L. This is paper accounting, not tax reporting.

Endpoint return is valid for the declared no-external-flow setting. Contributions or withdrawals can make it mistake owner cash for performance. Versioned cash-flow events and exact time-weighted returns address that. With no flows and identical valid endpoints, linked TWR agrees with endpoint return. Step 01 supplies the durable contract; Step 02 proves calculations and isolated offline attribution; Steps 03–05 present and package them.
