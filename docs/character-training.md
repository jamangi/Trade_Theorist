## Completing an entire curriculum

There is a gap in the implementation queue: no existing task promises all four books for every Character. Task completion must not be reported as curriculum completion. After each Character's setup, additional bounded reading runs can use the TASK-004 engine; they need not wait for all 23 engineering tasks. Later operational tasks still retain their dependencies and readiness gates. Full Event and Mean-Reversion learning needs a separately scoped work item; their presence in the library does not launch it.

For each continuation:

1. Select the actual supplied edition from the [current catalog](../library/catalog/characters.json). Resolve flagged edition/scope differences in a new curriculum version, retaining the original title order and earlier frozen versions. Recheck file fingerprints and register source identity, intended use and current authorization for that run.
2. Verify completeness against the contents and page sequence. For scans, create private OCR with page anchors and review text, tables, figures and formulae against the images. A readable cover, high page count or matching hash cannot prove a complete book.
3. Freeze the Character's existing prior before exposing the next unread source. Read in curriculum and source order with bounded calls, attributed claims, adversarial review and explicit accept/qualify/reject decisions. Do not load another Character's interpretation as formative memory, including for the shared Expectations Investing file.
4. Finish and validate the declared source coverage, checkpoint chain, memory delta, consolidated memory and any theory/test pair. Preserve contradictions and excluded sections. Save a completion artifact for that source before proceeding to the next book.
5. Report the number of completed books out of four for the pinned curriculum version. Only report curriculum completion when all four required sources have complete, reviewed coverage in order. A revised paper packet must be labeled as a revised curriculum, never as the missing books having been read.

The current `learn --character index_steward` command reports the audited foundation; it is not a command that autonomously reads a directory. The importer for the completed Bogle review is specific to that source. Other books require their own reviewed reading artifacts and source registration through the learning API. No new full-book reading or weight training was performed by this inventory update.
