`trade-theorist library check --catalog library/catalog/pilot.json --data-root <private-directory>` performs bounded HEAD requests to known URLs and caches results for seven days. It saves redirect, status and validator changes for review without downloading book bodies or changing permission/learning status. HTTP 200 proves neither book access nor a license; lack of cache validators also requests review. Use `--force` immediately before a planned ingestion. This is manual, with no scheduled checks.
